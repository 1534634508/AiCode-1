# 默认模型

「设置 → 默认模型」里除了新会话使用的默认模型，还可以给几个特定用途单独指定模型。

## 识图模型

决定 AI 用哪个模型看图片。

- **跟随当前聊天模型**（默认）：用你当前选中的聊天模型看图。
- **指定专用模型**：固定用某个模型看图，不随聊天模型切换。适合聊天用的模型不支持图片、或者你想用更便宜的模型处理图片的情况。

列表里每个模型旁边会标注是否支持图片输入，供你参考。注意这里**不做强制拦截**：如果你选了一个不支持图片的模型，识图会失败，AI 会收到错误信息并自行处理（通常会提示你换一个模型）。

识图的用法上有两点值得知道：

- AI 一次最多可以给识图模型 4 到 5 张图做对比分析，之后还能在同一个识图会话里继续追问，识图模型记得之前看过的图和问答。
- 图片默认会按需压缩以节省 token，也可以要求原图直传或更省 token 的低清模式。

## 生图模型

决定 AI 生成图片（调用生图工具）时用哪个模型，比如 OpenAI 的 `gpt-image-1`、`dall-e-3`。

- **未配置**（默认）：AI 调用生图工具会收到「请先配置生图模型」的错误提示，把这段话转告给你。
- **指定专用模型**：在你已添加的提供商里选一个支持图像输出的模型。生成图片会消耗该提供商的 API 额度，请在知情的前提下使用。

注意这里**不做强制拦截**：如果你选的模型实际不支持生图（或提供商没有图像生成能力），生图会失败，AI 会把错误信息原样带回。另外生图与识图不同，**不能跟随当前聊天模型**——普通聊天模型没有图像输出能力，必须在这里单独指定。

生图的用法上有几点值得知道：

- AI 在对话里生成图片后，图片会直接显示在聊天区；也可以同时保存为工作区文件（AI 会说明保存路径）。
- 支持指定尺寸、一次生成多张、画质与输出格式等参数，默认 1024x1024 单张 PNG。

## 标题总结模型

新会话发出第一条消息后，AiCode 会自动给会话生成一个标题。这里可以指定专门干这件事的模型。

- **跟随当前聊天模型**（默认）。
- **指定专用模型**：建议选一个便宜快速的小模型，标题这种活不需要好模型。

标题生成在后台异步进行，不会拖慢你的对话。如果生成失败或者取不到结果，会保留系统按首句截断的临时标题，不影响使用。

生成标题用的提示词也可以自己改，方式见「自定义提示词」。
